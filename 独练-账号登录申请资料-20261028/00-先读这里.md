# 独练账号登录：申请前准备

整理日期：2026-10-28。适用于当前独练 Android V1.25 与 iPhone 网页体验版 V1.0。

## 当前结论

你目前只有个人身份，没有营业执照，也没有开通相关云服务或开放平台账号。真实登录尚未接通；本资料包不含新的安装包，不代表账号功能已上线。

原目标保留：手机号验证码、微信授权、QQ 授权，最终关联到同一个独练账号。先保留本机使用，登录与跨设备数据同步分开实现。

## 先确定能走哪条路线

| 路线 | 当前条件与下一步 |
| --- | --- |
| 手机号验证码 | 腾讯云已不再接受新增个人自用短信资质。需符合要求的主体或真实授权，不能先买短信包再补资格。 |
| 微信授权 | 需申请对应网站 / 移动应用及登录能力。个人主体的可申请范围、认证费用与材料需在微信开放平台核实，尚未获批。 |
| QQ 授权 | 需 QQ 互联开发者及网站 / 移动应用审核。个人主体是否符合此次应用要求需在控制台核实，尚未获批。 |
| 邮箱验证码（可选过渡） | CloudBase 官方支持邮件代发；QQ 邮箱可接收验证码。仍需自己的云环境和配置。这不是 QQ 一键登录，也不会验证手机号。尚待你选择。 |

短信规则依据：[2025-09-12 官方公告](https://cloud.tencent.com/announce/detail/2127)。该限制从 2025-09-18 生效，并非本次软件代码造成。

邮箱方案依据：[CloudBase 邮箱验证码登录](https://docs.cloudbase.net/authentication-v2/method/email-login)。是否有试用、费用、额度和限制以开通时控制台为准，不承诺永久免费。

## 推荐操作顺序

1. 先决定是否接受邮箱验证码作为内测过渡。若坚持只做原三种方式，先核实各平台资格，不急于购买服务。
2. 如采用 CloudBase，使用自己的腾讯云账号注册、实名认证。实名证件只在官方平台提交。先确认可用套餐、配额和预算，再创建环境。
3. 为后续保留手机号接入，优先评估上海地域：CloudBase 当前官方短信登录文档只支持上海。选择环境前同时确认所选认证版本和计费。
4. 将实际环境 ID、地域、已启用登录方式填入“03-开通后回填.txt”。不用发送密码、AppSecret、SecretKey 或验证码。
5. 我再接入对应 SDK / 服务端验证，完成注册、登录、退出、账号隔离、旧记录迁移选择，并分别做安卓和 iPhone 联调。以真实验证码与真实授权成功为完成标准。

腾讯云入口：[腾讯云](https://cloud.tencent.com/)；CloudBase 入口：[云开发](https://tcb.cloud.tencent.com/)。这是注册与环境入口，不是已创建的独练后台。

## 文件怎么用

- `01-可复制的应用资料.txt`：名称、简介、现有包名与签名指纹。申请主体和回调地址留待实际确定。
- `02-各平台申请清单.md`：各项申请前置条件和适用端，避免把 PWA 当原生 iOS 应用申请。
- `03-开通后回填.txt`：只填写非秘密的环境、审核状态和应用信息。
- `图标-512.png`：沿用现有网页图标，供平台要求匹配时使用；具体尺寸和审核规范按平台提示。

本材料不包含用户训练记录、手机号用户列表、密钥、身份证或营业执照。现有安卓版和网页体验版仍按原方式使用。

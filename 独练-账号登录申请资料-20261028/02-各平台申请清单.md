# 平台申请清单

核对日期：2026-10-28。仅列已知事实与待确认项；所有账号、认证、域名与预算由用户本人掌握。

## 腾讯云与 CloudBase

- [ ] 注册自己的腾讯云账号，按真实主体完成实名认证。
- [ ] 核对 CloudBase 当前套餐、身份认证可用功能、配额、计费及预算提醒；再决定是否创建环境。
- [ ] 如选择该方案，为后续短信评估上海地域，保存实际环境 ID 和地域。
- [ ] 若选择邮箱内测：在身份认证的登录方式中配置邮箱验证码及邮件代发，核对发信额度，分别测试新用户注册与老用户登录。
- [ ] 配置实际使用的网站安全来源；安卓原生客户端另按选定接口准备，不把 Web SDK 当成已经适配 Kotlin。

来源：[短信验证码登录](https://docs.cloudbase.net/authentication-v2/method/sms-login)、[邮箱验证码登录](https://docs.cloudbase.net/authentication-v2/method/email-login)。

## 国内短信——当前暂停开通

个人自用资质已不能新增。先有符合要求的主体资质，或实际业务主体提供正式授权，再申请签名、模板和运营商报备。普通个人实名认证、高德个人开发者认证均不能替代这些资质。

短信签名应与符合要求的主体或商标匹配，不能因为应用叫“独练”就认定这两个字可直接通过签名审核。模板、有效期与验证码系统需一致；没有通过审核前不显示“验证码已发送”。

来源：[个人资质调整公告](https://cloud.tencent.com/announce/detail/2127)、[签名审核标准](https://cloud.tencent.com/document/product/382/39022)。

## 微信开放平台

入口：[微信开放平台](https://open.weixin.qq.com/)。

- [ ] 注册后核实当前个人主体能申请的应用类型、登录权限和认证条件，尚不能保证本项目获批。
- [ ] 安卓按“移动应用”准备真实包名、签名、图标、功能介绍与平台要求的材料。
- [ ] iPhone PWA 按网页实际授权场景评估，不按原生 iOS App 申请。Safari 与微信内置浏览器授权流程须分别验证；手机上的二维码页面不等于能直接唤起微信登录。
- [ ] 待固定域名、隐私说明与回调页面就绪后，填写实际可访问的地址。
- [ ] 应用和登录权限获批后，在受保护的认证后台配置 AppID / AppSecret，应用代码中不放 AppSecret。

CloudBase 官方接入前提是已获微信开放平台授权的应用，并不是注册 CloudBase 就自动获得微信登录。首次微信登录的未关联账号可能需要先通过其他方式注册并绑定。

来源：[CloudBase 微信授权登录](https://docs.cloudbase.net/authentication-v2/method/wechat-login)。微信主体资格、认证费用和审核要求仍需在其当前控制台核实，本材料不保证通过时间或费用。

## QQ 互联

入口：[QQ 互联](https://connect.qq.com/)。

- [ ] 注册开发者并核实当前个人主体是否符合独练对应应用的审核条件。
- [ ] 安卓移动应用和网页应用分别确认申请项，提交真实功能、图标与平台资料。
- [ ] 网站信息、域名、备案信息及授权回调按平台实际要求准备，不能把网页已可访问等同于 QQ 已审核。
- [ ] 获得审核通过的应用及对应 AppID / AppKey 后再接入。AppKey 仅配置在受保护的后端。
- [ ] 独立核对普通 QQ 互联与 CloudBase 的对接方式。公开的 CloudBase 基础登录方式没有直接列出普通 QQ；不能把 QQ 小程序登录误当 QQ 互联。

来源：[QQ 互联创建应用](https://wiki.connect.qq.com/__trashed-2/)。

## 上线前由开发侧完成

服务端身份验证；重复发送限制及防刷；验证码过期和错误处理；授权取消、state 校验和重复回调；稳定账号 ID；绑定冲突处理；退出与会话失效；A / B 账号数据隔离；本地旧记录迁移的明确选择；适配实际数据处理的隐私说明与账号管理。以上均为待开发、待验证事项。

现有用户数据不自动上传；界面不能写“已同步”，除非同步功能真实完成并通过测试。

# 独练 · iPhone 网页体验版 V1.0

这是独练的独立 PWA 体验版，面向 iPhone Safari。它不是 IPA，也不包含完整安卓版功能。

## 已实现

- 首页无预置训练计划；创建 / 编辑 / 删除计划，选择动作及顺序、组数、次数和休息时间。
- 逐组录入实际重量与次数，热身 / 工作组，暂停、继续、放弃、完成回顾、历史记录。
- 40 个动作的文字要点，从现有 Android 动作目录导出。
- 47 种食物的每 100 g 营养数据；按食用重量计算；包装食品按标签录入；饮水、体重记录。
- 当前浏览器本地保存，JSON 导出与校验后恢复。格式 `duolian-web / version 1`。
- 添加到主屏幕、离线应用壳、更新提示、窄屏排版、输入校验、未保存编辑确认。

不包含 GPS 路线 / 后台定位 / 自动计步 / 三维动作动画 / Android 备份导入 / 账号和云同步。
页面显示的零摄入表示没有记录；训练量只计算已完成的非热身组，不虚构徒手重量。

## 给 iPhone 测试者

1. 在 Safari 打开已经发布的 HTTPS 网址。不要使用本机 `127.0.0.1` 地址。
2. 分享 → 添加到主屏幕。如果系统提供“作为网页 App 打开”，保持开启。
3. 从主屏幕的独练图标进入，创建自己的第一份计划。
4. 请先添加到主屏幕再记数据。不同浏览器、Safari 标签页与独立网页 App 的存储可能分开。
5. 在“我的 → 导出备份”将记录存到“文件”；迁移入口或设备时，再在新入口恢复。

网页关闭后保存的数据仍在，但浏览器清理、系统回收或设备更换可能造成数据丢失，请定期备份。
训练计时根据已保存的时间戳计算，后台不保证倒计时通知；需要停表时主动暂停。
此版不请求位置或运动权限，不把训练 / 身体 / 饮食数据发送到服务器。托管服务可能记录普通访问日志。

## 本地开发

运行 `npm ci` 后，`npm test` 运行逻辑与隔离 DOM 流程测试。

使用静态 HTTP 服务器服务 `dist/`。本机 `localhost` 可测试 Service Worker；给手机使用必须采用有效 HTTPS 网站。
无需构建框架，最终静态文件都在 `dist/`，可以部署到域名根目录或子目录。

```text
python -m http.server 8767 --bind 127.0.0.1 --directory dist
```

修改发布资源后，必须同步提升 `dist/sw.js` 的缓存版本；用户确认更新后才切换 Service Worker。
部署应整体、原子地替换站点文件，不要把用户生成的备份或本地测试数据上传。

`tools/extract_catalog.py` 从父项目的 Kotlin 目录重新生成目录。只导出内置公开目录，不读取数据库、密钥或用户记录。
字体为系统字体；图标为本项目绘制；没有第三方远程脚本和分析代码。

## 验证边界

本轮完成 Node 逻辑与 DOM 流程自动检查，并在桌面浏览器窄屏检查首页和主要交互。
未在真实 iPhone Safari 完成主屏幕安装、分享导出和离线验收；桌面检查不能替代真机验证。

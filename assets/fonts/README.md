# 独练界面字体

V1.24内置未修改的Noto Sans SC可变字体，统一中文、拉丁字母及数字的字形。应用支持Android8.0以上，使用400、500、600、700字重；保留系统字体大小与显示缩放设置，空间不足时调整布局。

- 来源：[Google Fonts / Noto Sans SC](https://github.com/google/fonts/tree/main/ofl/notosanssc)
- 原始文件：`NotoSansSC[wght].ttf`，本地资源名`android/app/src/main/res/font/noto_sans_sc.ttf`
- SHA-256：`a3041811a78c361b1de50f953c805e0244951c21c5bd412f7232ef0d899af0da`
- 大小：17,772,300字节；未裁字、未修改字体内容。
- 许可：SIL Open Font License 1.1，原始版权声明和完整许可保存在`android/app/src/main/resources/fonts/NotoSansSC-OFL.txt`，随APK及安装包分发。

字体不需要运行时联网下载。未覆盖的特殊字符由Android字体回退处理，系统加粗文字设置等仍可能影响最终显示。

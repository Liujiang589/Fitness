# 独练 V1.12 手机体验清单

以下是验收步骤，不等于全部已通过。先备份再覆盖安装，勿卸载或清除应用数据。

1. 在关于页确认V1.12；检查旧计划、训练、备注、收藏及饮食仍可访问。
2. 首页上下滑动，切换计划库、动作库、饮食、历史页，检查图片出现时和列表滑动时的停顿。动作列表拖动时预览暂停，停下后可继续播放；详情的慢放、分解及视角仍可用。
3. 展开“近七天回顾”，核对完成次数、训练天数、走跑次数和距离；未结束记录不应算作已完成。饮食无记录时不能显示零摄入判断。
4. 有可比历史时，进步提示只比较同动作名称、同记录重量的正式组次数；改名、不同重量或热身不能混作可比结果。
5. 选米饭等食物，用生重、熟重筛选并核对来源与状态。输入150g时自动更新三大营养素；最近份量应带回原食物和原克数。
6. 自定义标签选择“每份”，例如30g一份，蛋白20g、碳水3g、脂肪1g，本次吃45g：应得到蛋白30g、碳水4.5g、脂肪1.5g，热量约151.5kcal。只在确需记饮食时保存，避免写入测试数据。
7. 按自己的真实训练检查计时、暂停/恢复、休息结束提示；切后台再返回时计时应按时间恢复，无需持续刷新所有训练卡片。
8. 检查高德地图加载与路线、定位权限、户外暂停和保存。发布压缩后须保留地图SDK功能；没有真实定位测试不能声称GPS已通过。
9. 检查小屏、大字体、横屏下的按钮与详细内容，以及备份导出/导入。重要数据先导出，不为测试覆盖真实记录。

如果仍有卡顿，请记录页面、进入步骤、机型、是否正在走跑/计步、手机温度与省电模式，便于继续定位。

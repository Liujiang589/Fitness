# 独练 V1.17 · 完整人体示范

2026-10-26。按用户提供的训练人物参考图，将简化程序人偶更换为带骨骼、真实人体比例和连续体表的完整模型。灰白人物配黑色训练短裤、鞋，胸腹、手臂、手指与面部结构可辨认。

- 40个内置动作统一使用新人体；目标区域为珊瑚色，辅助区域为浅金色。肌群颜色在顶点间过渡，短裤始终保持深色。
- 衣裤边缘切分源三角形，减少锯齿；保留光滑法线、固定光源和深度遮挡。
- 身体沿现有动作关节绑定，握持动作弯曲手指；俯卧撑、臀桥与反向卷腹的手掌贴近支撑平面，徒手深蹲手掌向下。
- 杠铃、哑铃使用圆柱握杆和有厚度的杠铃片，训练凳改为矩形软垫与金属支架。
- 保留播放、暂停、慢放、分解、拖动、放大与多视角。辅助路径仍可主动开启。

人体基础来自 Quaternius 的 Universal Base Characters Kit（Superhero Male），使用 CC0 1.0 许可；动作、器械、分区与渲染由独练制作。许可随APK与交付包保留，应用动作的“示范说明与动作管理”中有来源入口。详见 [assets/models/README.md](../assets/models/README.md)。

此为动作教学示意；颜色表示目标区域，不能测量个人实际肌肉激活。未知自定义动作仍提示暂无示范。

附带1440×620的循环GIF展示卧推、深蹲、弯举，来自应用相同Kotlin模型和投影代码的离线渲染，不是手机录屏。另检查40个动作的三阶段离线画面。手机上的显示和帧率仍需验收。

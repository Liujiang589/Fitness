# 独练 V1.29 · 专注训练与肌群展示

2026-11-02。versionName 1.29 / versionCode 43。

## 使用变化

- 训练默认进入“专注当前动作”；切换“查看全部动作”可查看和编辑整份计划。当前动作完成后进入下一个动作，同一超级组的动作始终一起显示，不改变训练顺序或数据。
- 常用输入保留重量、次数和完成勾选。点击组号旁的“···”打开沿用上次、组类型 / RPE / 休息、删除操作。删除仍需确认，完成勾选可撤销。
- 已完成组使用紧凑摘要，不再占用两块不可编辑的输入框。组号菜单仍可进入专业设置。
- 添加递减组移入每个动作标题旁的“选项”；“添加一组”仍在该动作底部。
- 训练头部使用浅色面板；普通训练用时缩小，休息倒计时突出，详细统计按需展开。
- 当前动作和动作详情新增原创正背面肌群图，主要肌群用珊瑚色、辅助肌群用浅金色，并直接显示肌群名称。
- 原有动态示范、慢放和进度拖动保留；不同视角和运动轨迹收进“视角与运动轨迹”。示范按需打开，不在训练列表自动播放。

## 肌群图的含义

图示沿用应用已有的动作肌群配置，用于理解主要与辅助区域，不表示实际发力强度、疲劳、恢复程度或医学结论。灰色表示未列为当前动作的主要/辅助区域，不意味着完全不参与。

压缩包中的“肌群图示意.png”由应用所用矢量路径渲染，用于查看卧推、深蹲、划船的颜色分区；它不是手机界面截图。专业动态示范仍使用原有模型，本轮没有将其替换成 openGym 动图。

使用独立 `独练-V1.29.apk` 覆盖安装，无需卸载。沿用原签名，支持 Android 8.0 及以上；升级前可导出备份。

# 独练 V1.13 手机验收

先备份，再覆盖安装。本清单是需要执行的实机步骤，不代表已经通过。

## 动作

1. 关于页确认V1.13；在动作库打开卧推、深蹲、弯举、下拉、硬拉、提踵等动作，观察体表、肌群、器械和关节运动。
2. 检查红色主要区域与文字目标是否一致；背部和腿后侧动作切到背面看。颜色是示意，不应显示实际肌肉激活百分比。
3. 检查路径随动作种类选对部位：引体向上看躯干、转体看双手；可隐藏、再次显示。
4. 暂停、慢放、进度拖动、三个阶段和放大正常；前/背/侧面没有明显裁切；小屏和大字体下所有按钮可访问。
5. 列表滑动不持续播放预览；进入后台后示范停播，返回后恢复。查看示范不更改计划、组数、重量或备注。

## GPS与地图

1. 在室外开阔处开始步行，等待稳定定位；静置约1分钟，观察近零地速时路程是否避免持续累加。不要用室内弱信号测试推断精度。
2. 走一段已知约200—400米的路线，与路段标记或参考设备比较，记录距离偏差、机型及信号状态。本轮没有预设一个已经验证通过的误差百分比。
3. 观察平滑速度/配速，突然改变速度后允许数秒响应；弱信号应提示质量不足，不持续给出旧的实时速度。
4. 地图定位标记与路线分别更新，精度圈可见；跟随时不会每次强制恢复缩放。手动拖动后可主动重新跟随。
5. 暂停时走动不增加本次时长、路线和步数；继续后不直线跨越暂停路段。退出页面及锁屏后按持续通知检查记录，结束后确认保存。
6. 断网时底图可能不能加载，但系统GPS不应因地图网络失败自动结束。不要为测试关闭或修改不必要的系统安全设置。

## 步数与旧数据

1. 确认本次走跑与当天已采集步数分别展示，不将系统健康应用全天步数当作本应用已覆盖的数据。
2. 等待首条计步读数再观察累计；连续走几十步，允许硬件延迟批量上报。未授权或无传感器应给出明确状态。
3. 检查旧计划、训练、路线、营养记录、收藏和个人备注仍在；旧历史不会被新滤波算法重新改写。

若仍发生漂移，请记录大概环境、机型、开始/停止时间和界面质量提示；无需公开精确家庭或工作路线。

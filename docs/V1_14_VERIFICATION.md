# 独练 V1.14 验证记录

2026-10-26。versionName1.14 / versionCode28，Android8.0及以上；原包名、原证书的Release优化变体。

## 本轮改动

- 删除首页待训练状态中自动挑选动作、默认回退到深蹲的卡片；实际训练的当前动作示范保留并标明上下文。
- 首页走跑入口改为整卡点击，说明用途或展示未结束的运动状态；计划管理按钮扩大点击范围并补读屏名称。
- 走跑固定操作栏增加“放弃本次记录”。确认框区分保存/放弃、展示本次距离和时长，返回不会自动恢复暂停的记录。未获得路线时说明保存内容。
- 放弃命令串行执行，绑定确认时的运动ID，数据库删除未结束检查点成功后才清空记录器；检查点删除失败时保留恢复数据、暂停并提示重试。已保存历史受保护，当天已采集步数保留。传感器、定位和通知按现有日常计步设置收尾。
- 成功后过滤Room异步通知尚未到达时的旧检查点，避免界面短暂重新出现已放弃记录；确认数据已刷新后解除临时过滤，避免影响以后从备份恢复同一ID的运动。回到顶部展示结果。
- 起始页移除空地图，今日步数集中展示；活动中标题为收起，说明仍记录。成功提示与错误分离，设置入口收纳到详情。
- 动作搜索无结果时可一键重置，更换筛选回到列表顶部。

## 写作约定

- **每个版本至少一份验证记录**：`V1_<版本>_VERIFICATION.md`，写清楚构建命令、测试数量、Lint 结果、APK 校验值。
- **只写能证明的结论**：构建通过不等于界面验收，截图不等于 GPS 精度；未验证的部分明确写「未验证」。
- **行为变更写进 `CHANGELOG.md`**，细节与边界留在对应版本的文档里，不在两处重复。
- 文件名前缀保持 `V<主>_<次>_`（如 `V1_19_OUTDOOR.md`），界面类文档用 `UI<编号>_`。

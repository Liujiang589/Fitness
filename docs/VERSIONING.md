# 版本命名

用户可见版本统一使用两段格式：**V1.2**。

- 常规更新依次为V1.3、V1.4等；较大的产品升级再变为V2.0。
- Android versionName保存数字部分，例如`1.2`；关于页和下载页统一显示`V1.2`，不向用户展示内部构建编号。
- Android versionCode独立递增，当前为16，保证可覆盖升级之前的versionCode15。
- 对外安装包命名为`Duolian-V1.2.apk`，不附加debug或多余的补丁段。构建仍使用现有调试签名，文件改名不代表签名类型改变。
- 历史0.x.y安装包与验证文档保留；下载服务兼容历史三段命名，当前下载入口只提供最新发布包。

V1.2沿用原0.12.0的界面和功能，仅调整版本命名及对应的下载文件解析。

# 版本命名

用户可见版本统一使用两段格式：**V1.20**。

- 后续常规更新依次为V1.21、V1.22等；较大的产品升级再变为V2.0。
- Android versionName保存数字部分，例如`1.20`；关于页和下载页统一显示`V1.20`，不向用户展示内部构建编号。
- Android versionCode独立递增，当前为34，高于V1.19的33。
- 对外安装包命名为`独练-V1.20.apk`，不附加debug或多余的补丁段。V1.12使用非debuggable的Release优化变体，仍使用历史开发证书以覆盖升级；尚未更换应用商店签名。
- 历史0.x.y安装包与验证文档保留；下载服务兼容历史三段命名，当前下载入口只提供最新发布包。

V1.2沿用原0.12.0的界面和功能，仅调整版本命名及下载文件解析；V1.3新增动作动态示范，详见[V1_3_ACTIONS.md](V1_3_ACTIONS.md)。

# 独练 V1.26：安卓版账号页面准备版

2026-10-28。仅处理安卓注册 / 登录入口，苹果网页版暂停，本轮未改动或重新发布。

## 这版可以查看什么

打开「我的」，原头像卡片改为「本机使用」，明确当前未登录。点「注册 / 登录 · 准备中」进入原生全屏账号页面，可切换注册与登录视图、查看手机号验证码表单样式和微信 / QQ 的接入说明，并随时返回继续本机使用。

页面采用与现有应用一致的系统风格：浅色分组卡片、宽按钮、滚动内容、顶部返回、底部本机使用入口。系统返回可退出；没有强制登录或打开应用就弹出注册页。

## 尚未开放

**本版没有真正的账号注册或登录服务。**手机号与验证码输入框、发码和提交按钮保持禁用，显示尚未开放。微信 / QQ 行只打开说明，不会假跳转或假授权。

当前不会收集手机号、保存验证码、创建在线账号、切换账号数据或上传训练记录。原本地数据库、备份格式、走跑和训练功能未迁移。旧记录归属选择、账号隔离、会话管理、绑定 / 解绑、注销和云同步仍待实现；不能把此版本当作这些功能已经完成。

## 为什么还不能真正注册

尚无用户自己的认证服务环境，也没有获批的短信签名、微信或 QQ 应用。用户已说明只有个人身份、无营业执照；国内短信资质限制已核实。平台条件和申请资料见 `ACCOUNT_LOGIN_PLAN.md` 与项目根目录的 `独练-账号登录申请资料-20261028/`。

开发下一阶段需先有可用的认证方式与环境，再完成真实身份验证及数据归属隔离。不能只解除按钮禁用，或把手机号码当成已经验证的用户身份。用户未选择邮箱方案，本版没有加入邮箱或密码注册作为替代。

## 安装与验证范围

交付 APK 位于原项目目录，沿用现有签名以支持覆盖安装。升级前建议从「我的 → 导出全部数据」备份。无需卸载旧版。

本轮未操作手机，未做真机视觉或触控验收。编译与静态检查不能代替真机验证，更不代表真实验证码或第三方授权已验收。该包用于查看账号页面，不推送为“登录已上线”的在线更新。

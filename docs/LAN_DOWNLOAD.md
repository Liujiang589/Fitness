# 用手机浏览器下载独练

这个入口直接提供原始 APK，不需要 ZIP 解压或修改后缀。电脑和手机使用同一 Wi-Fi，手机用系统浏览器或浏览器扫码入口打开二维码，点击“下载 Android 安装包”，下载完成后按系统提示安装。微信内打开页面时会提示改用浏览器。

## 启动

在项目根目录执行：

```powershell
.\tools\Start-Download.ps1
```

默认选择活跃 Wi-Fi IPv4，端口为8765；后台隐藏运行，不需要一直开着终端。启动后会输出下载页地址、APK地址和二维码位置。当前版本以根目录 `Duolian-V1.5.apk` 这类两段版本文件名为准，版本取自 Android 构建配置。下载页显示V1.5，不附加内部构建编号；历史三段版本文件名继续兼容。

可以指定地址或端口：

```powershell
.\tools\Start-Download.ps1 -BindAddress '192.168.x.x' -Port 8765
```

Python 默认使用本机已配置的 Codex bundled Python，或 PATH 中的 Python，也可通过 `-PythonPath` 指定 Python 3.9+。首次缺少二维码库时，只会把 `qrcode==8.2` 安装到项目的 `.local-download-deps/`；不修改全局 Python。依赖版本见 `tools/requirements-download.txt`。

## 手机使用

1. 让手机与电脑连接同一 Wi-Fi。
2. 用手机浏览器扫码打开下载页；或者把启动脚本输出的网址粘贴到手机浏览器。
3. 点击下载原始 APK，等待完成，在浏览器下载列表或通知里点该 APK。
4. 首次可能需要允许该浏览器安装应用；安装时仍需按系统提示确认。

同一 Wi-Fi 不代表手机已经验证可达：访客网络隔离、防火墙或网络切换仍可能影响连接。页面打不开时先确认电脑服务仍在运行、两端同网段和当前地址一致；需要时只为该程序、该端口放行局域网访问，不必关闭防火墙。

## 更新、二维码与停止

地址和IP不变时，每次发布新的根目录 APK 后，下载页与 `/latest.apk` 自动指向构建配置中的新版。准备新版本但 APK 尚未发布时返回503，避免误下旧包。IP变化或端口变化时，重新启动并使用新二维码。

生成文件位于 `.local-download/`（git忽略）：

- `download-qr.png`：当前下载页的二维码；
- `download-url.txt`：当前网址；
- `server.json`：本地进程信息；
- `server.log` / `server-error.log`：运行日志。

停止服务：

```powershell
.\tools\Stop-Download.ps1
```

停止脚本核对 PID 对应的是本项目的 `serve_download.py` 后才停止进程，避免误杀其他程序。电脑休眠、关机或进程退出后入口不可用；再运行启动脚本恢复。V1.5起支持应用内检查、下载和系统安装入口，使用同一局域网服务；当前没有公网固定下载页，也未上传安装包到外部平台。详见[应用内更新](APP_UPDATES.md)。

## 服务范围与验证

仅允许下载页、二维码、最新版 APK、版本信息及健康检查路由。没有目录浏览、上传接口、源码路径或签名文件访问。服务绑定指定的私有IPv4地址，不监听 `0.0.0.0`，不设置路由器端口转发。

支持 APK MIME 类型、可识别的 `.apk` 文件名、HEAD、断点续传和SHA-256；版本变化后旧ETag不能继续拼接不同版本。页面和版本信息不缓存，避免误装旧版。

```powershell
python -m unittest discover -s tools -p test_download.py -v
```

测试覆盖完整下载、断点续传、版本变化、非法范围、敏感路径拒绝、QR图像、HEAD/版本信息、绑定范围及发布切换，以及更新说明字段、说明热更新与非法说明拒绝，共12项。

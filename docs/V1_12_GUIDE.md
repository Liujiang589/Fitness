# 独练 V1.12 · 周回顾、饮食与流畅度

## 看懂这一周

“训练 → 今天 → 这一周，留下了什么”提供近七天回顾。展开后先看练了什么、哪里有记录上的进步、下一步如何安排，详细数字再展开查看。

采用今天及此前六天，与紧邻的前七天比较。只统计已结束的力量训练和走跑；暂停时间不计入力量训练活动时长。两类运动分别展示，不直接相加成总运动时长。次数进步仅比较同一动作、同名称、同记录重量的已完成正式组，不把热身或递减组算作正式组进步。

饮食缺记不当作零摄入。平均热量只计算有记录日期内的已记条目，不据此判断是否吃够，也不把次数进步解释为体型变化。

## 饮食少填一些

- 食物库增加生重、熟重、干重、即食/其他筛选。先核对食物状态，再填实际可食部克数；生熟重量不会自动互换。
- 最近份量可一键复用食物和克数，再按本次用量调整。营养仍采用该记录保存的快照，不悄悄换成当前食物库数值。
- 包装标签可以选择“每100g”或“每份”。选择每份时填写包装标注的每份克数及三大营养素，独练按本次吃的克数换算。每100ml不等于每100g。
- 内置食物仍自动估算营养，自定义包装标签只需录入一次，之后可从最近份量调用。旧版无克数记录保留原总营养数值，不猜测重量。

## 滑动优化

高清照片保留，改为后台解码和有上限的内存缓存；数据库内容解析和备份编解码避开界面线程；缩小计时器和户外状态更新影响的界面范围。动作预览在列表拖动时停播，静态示范绘制缓存复用。安装包启用发布优化和资源压缩。

V1.12沿用旧包名及签名，Android 8.0以上可覆盖安装。先导出备份，不要先卸载。包名保留是为了兼容升级与高德绑定；应用展示名称仍统一为“独练”。数据库及备份格式不变。

安装ZIP后请在文件管理器解压，再点其中的APK；若想省去解压，可直接传输项目根目录的“独练-V1.12.apk”。微信可能限制直接启动安装器，安装请使用系统文件管理器。

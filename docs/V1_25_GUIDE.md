# 独练 V1.25 · 整体体验整理

2026-10-27。Android versionName 1.25 / versionCode 39。沿用原包名和签名，Android 8.0 及以上可以直接覆盖安装 `独练-V1.25.apk`，无需先卸载。

## 这次变化

- **页面切换更连贯**：底部页面与饮食页分别保存界面状态；动作搜索、筛选、历史月份和日期、工具输入与列表位置在切换后恢复。离开的页面退出组合，动作预览不会为了保留页面状态继续在背后播放。首页“今天”和“计划库”分别记住列表位置。这里指界面状态恢复，不等于所有未保存输入都已写入数据库。
- **训练列表更轻**：每个动作标题、每一组和操作区域分别按需显示，替代把整份训练塞进一个列表项的方式。保留超级组顺序、上次参考、动作示范、正式/热身/递减组及 RPE。
- **记录输入更稳**：有效的重量、次数输入由 ViewModel 延迟 600ms 保存，滚动或切换页面不会取消待保存任务；暂停、结束和导出前先保存待写入的有效输入。完成、删除、放弃时清理对应待写入任务，旧会话输入不能修改另一场训练。应用被系统终止前尚未写入的输入仍可能丢失。
- **保存有结果**：体重、饮水、自定义动作、组设置和饮食窗口等待实际写入成功后再关闭；失败时显示原因、保留输入，允许重试。修改后取消会确认是否放弃。数字字段使用数字键盘，动作说明支持多行。
- **训练有收尾**：结束后显示已保存回顾，汇总完成动作、组数、用时和容量，并提示未完成组不计容量，可以直接进入历史。
- **排版更统一**：首页与历史分段选择使用统一样式；工具入口、历史摘要、身体趋势、个人训练积累和训练统计按文字实际宽度换列。窄屏/大字体下训练输入上下排列，时钟选择合适字号，删除组的按钮扩大触控范围。后台保存时进度条区域保持固定高度，避免内容上下跳动。
- **回顾更准确**：历史筛选无结果时提供“查看全部记录”；选择时间范围会清掉单日筛选，避免两种条件叠加产生误解。每个动作分别显示当次估算 1RM，不再把不同动作混成一个最大值。历史明细取消按更早一次记录反复调整当前默认重量的按钮；估算、负荷、肌群与个人纪录仍可在专业分析和工具中查看。
- **走跑信息更清楚**：当天没有采集记录时显示“尚未采集”，避免把未知当成 0 步；日期只在界面活跃时更新，返回页面后刷新。正确区分操作超时与生命周期取消。保留已有定位隔离、路线质量校验、暂停/继续/取消/保存与位置授权流程。

## 安装后建议查看

1. 首页进入计划库，切换到“我的”再返回；到动作库搜索后切换页面，再返回查看搜索条件。
2. 开始一份自己的训练计划，修改重量和次数后滚动到其他位置；稍后回来查看。只有勾选完成的组会计入完成组数，正式组等按原规则计入容量。
3. 结束训练后查看回顾，再进入历史明细；按时间筛选无结果时可以回到全部记录。
4. 尝试编辑一条记录并取消，检查是否出现放弃修改确认。

## 数据与验证边界

数据库 schema 1、备份 v4、原包名和签名保持不变。已有计划、训练、饮食、历史轨迹以及已采集步数沿用原数据；模型、字体、高德配置与路线计算门槛不变。

本次遵循“先做安装包，暂不操作手机”的要求，没有安装或控制用户手机。编译、逻辑测试和包校验不能代替真机的视觉、滚动帧率、GPS 精度、锁屏耗电与长时间运动检查。具体结果见 [验证记录](V1_25_VERIFICATION.md)。本地交付和下载页文件更新不代表公网网站已发布。

字体与模型许可随安装包和压缩包保留。

容量使用已完成正式组的重量×次数，不包括特殊单侧/辅助/超级组/减重组。动作图形是独立示意；本地视频为临时播放。饮食页面显示今天，可保存其他日期但尚无日期历史浏览器。挑战规则仅列入模型。备份限本预览格式与2MiB文件，不迁移原版账户或私有备份。

预览所有外部连接被CSP禁止；没有外部字体、脚本、图片、分析SDK或服务器。正常写入仅在当前预览专用localStorage键，源APK与原应用数据未被修改。本轮未安装工具、改系统设置或变更其他项目。

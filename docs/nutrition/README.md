# 食物克数与营养自动换算

## 数据来源

内置条目取自 USDA FoodData Central **SR Legacy，April 2018**。这个历史数据集版本固定，适合离线计算与复现；没有把它标为最新成分数据。

- [官方下载与版本说明](https://fdc.nal.usda.gov/download-datasets/)
- [SR Legacy CSV 原始压缩包](https://fdc.nal.usda.gov/fdc-datasets/FoodData_Central_sr_legacy_food_csv_2018-04.zip)
- [USDA 食物成分与每100g可食部说明](https://catalog.data.gov/dataset/composition-of-foods-raw-processed-prepared-usda-national-nutrient-database-for-standar-28)
- [47 条精选条目及原始描述、数值、FDC ID](usda-sr-legacy-selection.json)

中文名称、分类与别名为项目整理；状态说明保留生、熟、干重、去皮、烹调方式等关键区别。每条记录可以从应用打开对应 FDC 来源页。

## 换算方法

蛋白质、碳水、脂肪均来自数据集的每100g可食部值，营养素 ID 分别为 1003、1005、1004。

```
本次某营养素(g) = 每100g的该营养素(g) × 本次可食部重量(g) / 100
本次热量(kcal) = 蛋白质(g) × 4 + 碳水(g) × 4 + 脂肪(g) × 9
```

热量沿用应用原有的三大营养素估算法，未把 USDA 的热量列混入统计。食物纤维、专用能量系数及包装舍入可能导致估算热量与数据库或包装热量不同。界面已说明算法并使用“预计 / ≈”。计算保存完整浮点数，显示时才四舍五入。

例：长粒白米饭（无盐、熟重，FDC 169757）150g，得到蛋白质 4.035g、碳水 42.255g、脂肪 0.42g、估算热量 188.94kcal。

## 交互与适用范围

- 选择明确条目并输入克数；默认食物库模式不要求输入三大营养素。
- 支持中文名称、别名、英文关键词搜索，以及主食、肉蛋鱼、奶豆、水果、蔬菜、坚果油脂分类。
- 生重与熟重分别建条目；可食部称重，去除未计入条目的骨、壳、皮等。熟重条目按说明选择，烹调油可另记。
- 饮品当前按克称重，不自动将 ml 当成 g。
- 包装食品可录入一次**每100g**标签，然后从最近使用中直接选用并按本次克数计算。
- 未命中食物或混合菜肴时明确提示，不自动挑选名字相近但状态不同的条目。组合餐可以按食材分别记录；品牌、配方和油量差异仍会影响结果。
- 最近使用包含有重量和成分依据的旧条目；它会复用当时保存的营养快照。

## 兼容与持久化

`Food` 新增可空字段 `grams`、`catalogId`、`nutritionSource`、`preparation`，Room 数据库结构保持版本1。旧记录缺少这些字段时仍按原来的总营养值读取和编辑，不推断原重量。

已保存饮食保留营养快照；重新编辑同一条记录的克数时按该快照同比换算。更新食物库不会重算旧记录。备份 v3 包含新字段，新版导入 v1 / v2 / v3；旧版应用不支持 v3。

## 重新生成条目

解压官方 SR Legacy CSV 后运行：

```powershell
python tools/build_food_catalog.py '<解压CSV所在目录>'
```

脚本按确定的 FDC ID 抽取三大营养素，遇到缺值直接失败，生成 `FoodCatalog.kt` 和本目录 JSON 快照；不估填缺失值。原始全量数据不打进 APK。

# 独练 V1.16 · 平滑人偶示范

2026-10-26。将V1.13–V1.15中容易造成不适的凸起肌肉造型改成干净、中性的哑光人偶。

- 去掉凸出的胸肌、腹肌、背肌与手臂肌肉对象，以及鼻子、耳朵等面部细节。
- 躯干和四肢采用平滑体表；肘、膝的连续曲线过渡替代独立关节球。四肢根部埋入躯干，减少明显断开的接缝。
- 主要肌群为柔和珊瑚色，辅助肌群为浅金色，其余区域统一灰白；高亮直接标记在体表上，没有肌肉块起伏或颜色脉动。
- 阴影减轻，器械统一中性灰，保留动作姿态、器械、慢放、分解、进度与多视角。
- 辅助轨迹默认隐藏，需要时可点“显示轨迹”。40个内置动作都使用同一套新造型。

本版是独练自行实现的动作示意，参考用户希望的清楚、平和的人偶表达，没有提取或分发其他应用的模型素材。高亮表示教学目标区域，不是个人实际发力测量。

附带960×620的循环GIF展示弯举与深蹲，来自应用相同的Kotlin几何和投影算法离线渲染，不是手机录屏。其背景、色彩与默认关闭轨迹的显示方式对应本版。

Android8.0以上，V1.16/内部30。建议先导出备份，再覆盖安装，不先卸载。沿用原包名和签名，训练、营养、走跑与备份格式保持不变。

本轮手机连接中断后，用户选择先取安装包，因此没有安装V1.16到手机，也未执行真机模型验收。见[V1_16_VERIFICATION.md](V1_16_VERIFICATION.md)。

# 独练 V1.21 · 计划编辑细节

2026-10-26。继续完善V1.20的完整计划编辑器，保留首页固定入口、完整动作选择与排序、等待保存成功、失败重试和取消确认。

本次调整：

- 保存、切换到动作选择页、返回和取消使用编辑弹窗自己的焦点管理器，修正对底层Activity清理焦点的问题，让输入框退出焦点的处理作用于当前编辑窗口。
- 收起进阶设置时，仍显示当前训练方案与动作编排摘要；进入编辑时可以看见自己已有的设置。
- 常规、两两超级组和整轮循环分别显示对应说明，不再把整轮循环也描述成相邻两动作配对。
- 输入错误分别解释计划名称、组数、次数、休息、删除的动作、重复动作和超级组条件。粘贴的数字允许首尾空格；原有数值上下限、零次数和0秒沿用全局休息的含义保留。
- 动作与训练日使用不可变List状态和显式保存器，增删/排序替换新列表；草稿和原计划ID、排期、方案继续保留。

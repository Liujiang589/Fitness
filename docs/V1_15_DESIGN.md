# 独练 V1.15 · 清爽的界面与字体

2026-10-26。参考Apple界面中常见的内容层级、一致性和清晰排版，将独练原先偏运动海报的视觉调整为轻量的应用界面。

## 视觉规则

- 背景为浅灰白`#F5F5F7`，卡片为白色；正文近黑`#1D1D1F`，辅助文字`#6E6E73`，交互重点蓝`#0066CC`。减少草绿、荧光色和大面积深色装饰，红/橙/绿仍用于实际的风险、阶段或定位状态。
- 统一系统无衬线字体和15级排版：页标题32sp、卡片标题18–22sp、主要正文17sp、普通说明15sp、辅助说明12–13sp。正文常规字重，标题和关键数字适度加重，不再普遍使用粗重字。
- 中文不再使用负字距，正文保持舒适行高；数字启用等宽数字特性，具体字形取决于设备系统字体。沿用Android系统字体，没有随包分发Apple专有字体。
- 白色分组卡片约20dp圆角、20dp内边距，边线减少；导航采用浅色底栏、蓝色选中状态、统一线性图标。日期和短页标题代替装饰性英文标语。

## 页面

首页照片与文字分区，不再叠加多层渐变；照片顶部对齐，避免窄图条裁掉人物面部。计划标题使用完整内容宽度；按钮保持明确的主操作。周历合并为一张卡片，大字体时可横向滚动日期，避免挤压。

饮食横幅采用独立图片与文字区域；表单输入采用常规字重。动作库的背景、图示与卡片统一到灰蓝体系，肌群教学着色保留原有含义。

走跑距离与配速改为白色统计卡，辅助文字和单位层级减轻，定位正常使用浅绿状态。个人页使用浅色身份卡；深色仅保留于需要聚焦的训练/计时或作者卡。启动图标与系统重点色也统一为蓝白。

没有新增持续模糊、背景采样或装饰性循环动画；沿用异步图片缓存和滚动时暂停预览的方式。未据此宣称真实帧率提升。

V1.14的放弃走跑、确认提示、当天步数保留和当前动作示范行为继续保留。训练、营养、路线与备份数据格式不变。

## 安装与检查

V1.15（内部29），Android8.0以上，原签名覆盖升级。建议先导出备份，不先卸载。安装后检查首页、工具、动作、历史、我的、饮食和走跑页的字体与配色；在系统调大字体后，检查页标题、操作按钮、周历及确认框。

实际构建与显示检查边界见[V1_15_VERIFICATION.md](V1_15_VERIFICATION.md)。本轮仅交付本地APK与资料包，没有重新部署WorkBuddy公网站。

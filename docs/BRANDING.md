# 产品名称统一：独练

2026-10-23，V1.9 起统一对外名称为 **独练**。名称简短，体现自主安排、专注训练和记录自己的进步。

## 用户可见的名称

- 安卓桌面和系统安装界面：独练，统一来自 `app_name` 资源。
- 应用首页、关于作者、计时和运动通知：独练。
- 安装包：`独练-V1.9.apk`；后续沿用 `独练-V版本.apk`。
- 压缩包及目录：`独练-V1.9-安装包.zip` / `独练-V1.9-安装包/`。
- 备份、自动备份、导入前备份和GPX导出文件以“独练”开头；GPX的创建程序标识也为“独练”。
- 下载页模板使用中文品牌名；本地下载的HTTP头使用UTF-8文件名。旧客户端不识别UTF-8扩展参数时，提供正确拼音 `Dulian` 作为ASCII兼容文件名。

## 升级和授权兼容

Android applicationId/namespace 继续为 `app.duolian.local`，签名证书、数据库名称、备份格式标识 `duolian-native`、现有更新地址以及系统内部组件标识保留。它们用于识别已安装应用、读取旧数据和高德Key绑定，不能将对外改名等同于更换这些标识。

下载服务优先使用中文名称的当前版本APK，仍兼容历史 `Duolian-V版本.apk` 和旧三段版本文件；过去已经交付的APK、ZIP及验证记录保留，不改写历史文件。先前版本公开下载链接所引用的实际文件名仍然有效；新的页面下载属性使用“独练”作为保存名称。

## 范围和检查

本轮更新源码内的应用名称、标题、导出名称、交付包、下载工具及页面模板，不重部署WorkBuddy的公网网站。新包为V1.9/versionCode23，需覆盖安装后查看新名称。

构建、签名、中文下载HTTP头和兼容性验证见 [V1_9_VERIFICATION.md](V1_9_VERIFICATION.md)。高德街道加载、真实定位和锁屏仍需手机验收。

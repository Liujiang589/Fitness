# 独练 V1.11 手机体验清单

先导出备份，再覆盖安装；不要卸载旧版。下面是需要在手机执行的验收步骤，不代表已通过真机验证。

## 首页

1. 打开“训练”，默认“今天”页应优先显示今天可做的事，不连续铺开全部计划、模板和营养数字。
2. 点“计划库”，原有计划可查看、展开、编辑、复制和删除；可选模板、周排期仍可访问。不要为了测试删除自己的重要计划。
3. 当天有排期，主卡片显示对应计划；完成后不再次把同一计划推作未完成安排。无当日排期时显示自由安排或休息状态。没有计划的新安装仍由用户创建，不自动填预置训练。
4. “步行与跑步”“饮食手记”“身体记录”和本周足迹都能找到；展开周数据和进入历史分析后专业数据仍在。

## 动作指导

1. 首页动作学习卡、动作库、计划内的“看要领”均可打开指导。观察矢量示范是否清楚，慢放、暂停、拖动、视角和放大操作正常。
2. “动作要领”先显示简短重点和呼吸；展开“完整分解说明”查看三个阶段，高亮随演示阶段变化。
3. 切到“常见错误”“替代动作”，能看清具体内容。选择替代示范后标题、动画、重点和器械都对应新动作；“返回原动作”回到最初项目。
4. 查看替代动作前后，计划、默认重量、个人备注和训练记录不应改变。没有合适替代的动作应明确提示，自定义未知动作不套用错误示范。
5. 开始自己的训练，下一组或动作旁可直接查看要领；指导内没有编辑/删除入口，关闭后仍是当前训练和原组数据。建议仅在确实准备训练时验证，避免产生无意义记录。

## 显示与回归

- 小屏、大字体、横屏下，标题、按钮、播放器和底部操作应可访问，不应出现操作被截断。
- 切后台后动画应停止，返回后恢复；关闭系统动画时尊重现有静态默认，仍能手动操作详情。
- 检查旧计划、组记录、收藏、备注和饮食仍在。户外走跑沿用V1.10，可按其清单回归暂停/保存。
- 如有问题，记录机型、系统版本、字体大小、进入步骤和截图。实际手机UI运行及素材观感需要这一步确认。

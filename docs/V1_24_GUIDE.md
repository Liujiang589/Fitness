# 独练 V1.24 · 字体适配与走跑稳定性

2026-10-27，versionName1.24 / versionCode38，Android8.0以上。沿用原包名与证书，直接覆盖安装“独练-V1.24.apk”，不先卸载旧版。

## 界面变化

- 内置Noto Sans SC，中文、数字、英文使用同一字体家族，减少不同品牌和主题字体造成的字形差异；普通、中等、半粗和粗体分别使用400/500/600/700字重。
- 保留手机的系统字体大小和显示缩放。字号不强行锁定为1倍；手机设置不同，最终大小仍会不同，但布局会给文字留出空间。
- 首页标题与操作按钮、今天/计划库/创建计划按实际测量宽度排列，空间不足时上下排列。
- 周历按实际数字宽度选择一行或多行显示，完整保留七天；饮食与身体卡片、周数据根据可用宽度换列。
- 营养入口与供能图例支持换行。走跑页的大字体模式可以纵向滚动查看指标和地图，时长与配速按宽度重排，距离主数字按可用空间选择字号。

## 走跑变化

- 沿用V1.23的定位SDK依赖修复与独立辅助定位进程。
- 辅助定位启动15秒仍没有有效位置或错误响应时，释放连接、提示回退到系统定位；不会停止运动计时或伪造路线。
- 旧通知或延迟确认携带的会话编号与当前运动不符时，拒绝操作，防止暂停、继续或结束另一场运动。
- 加固街道地图恢复、暂停、触控、监听设置和销毁时的Java异常处理，销毁可以重复调用。原生进程崩溃不能依靠Java异常捕获解决，不能将此改动视为已证实消除所有地图/定位崩溃。

## 数据与检查

计划、训练、营养、历史轨迹和当天已采集步数沿用原数据。数据库schema1、备份v4、路线质量门槛、权限与更新源不变。

安装后可以先检查首页创建计划入口和周历，再检查步行/跑步的准备、取消、开始、暂停、继续、保存。没有可靠路线时，仍可保存时长和已采集步数；网络位置不会增加路线里程。

如果仍闪退，重新进入“我的 → 异常诊断 → 复制信息”提供错误信息。按用户本轮选择，本次只交付安装包，没有覆盖安装或操作手机，实际运动和多机型效果仍待验收。验证结果见[V1_24_VERIFICATION.md](V1_24_VERIFICATION.md)。

字体来源、文件摘要与许可见[字体来源](../assets/fonts/README.md)。[Android字体说明](https://developer.android.com/develop/ui/compose/text/fonts)和[Flow布局说明](https://developer.android.com/develop/ui/compose/layouts/flow)作为实现参考。

# 独练 0.11.0 · 快速训练与食物自动换算

本版在 0.10.0 视觉系统上优化日常记录，版本号 0.11.0 / versionCode 13。

## 训练

- 每组重量、次数在列表内直接填写，数字键盘输入；有效输入停顿 0.6 秒后自动写入本地。
- 点击完成时，在一个 Room 事务内保存当前重量、次数和完成状态，再启动休息计时，避免输入尚未自动保存就勾选造成丢值。
- 从当前训练开始前已结束的同动作记录中，读取最近一次有正式组的训练；每行对照相同组类型、相同序号的上次表现，并可点“沿用”。
- 不把上次热身组当作本次正式组，也不把其他动作的纪录当成当前动作。
- 顶部显示接下来的动作与组，下一组有边框高亮；超级组按每轮交替顺序处理。
- 点击已完成组的勾选可撤销，同时清理休息计时与容量计入。延迟到达的输入保存不会覆写已完成组。
- RPE、组类型、独立休息等高级字段保留在“设置”中；行内编辑保留这些元数据。
- 键盘避让与 adjustResize；食物选择、克数与训练输入支持状态恢复。

## 饮食

新增食物选择与克数表单、47 个可追溯离线条目、实时营养预览、最近使用、每100g包装标签复用，以及历史手动记录兼容编辑。

详细数据来源、算法与边界见 [nutrition/README.md](nutrition/README.md)。

## 兼容

包名与签名继续沿用；不改 Room 表结构。新备份使用 v3，新版兼容导入 v1 / v2 / v3。旧版应用不能导入 v3 备份，升级前的历史安装包与既有备份保留。

## 验证

最终结果见 [UI011_VERIFICATION.md](UI011_VERIFICATION.md)。本机模拟器存在此前已记录的加速与启动问题，本版没有重复修改系统环境；未在个人手机执行会替换数据的设备测试。

训练总结、周报和更深入的计划编辑沿原路线安排在后续版本。

# 独练 V1.18 · 深蹲手臂修正

2026-10-26。修正徒手深蹲示范中双肘外翻、前臂下折和腕部扭转的问题。

原姿态的逆向运动学目标把肘部拉向两侧；更换完整人体后沿用了相同姿态。此外，躯干前倾时把旋转传到上臂，而手掌保持向下，使前臂与手腕相拧。

本版让双臂自然向前伸、肘部微屈、左右保持对称，肘腕位于接近肩高的范围。上臂在这个动作中不再继承躯干的额外旋转；下蹲时前臂和手掌保持方向一致。不是将动作隐藏或只换缩略图；动作列表、详情与训练中共用同一套修正后的姿态。

保留V1.17完整骨骼人体、衣裤、肌群颜色、40个动作及播放/暂停/慢放/分解/视角。红色仍代表主要肌群，黄色代表辅助肌群，为教学示意。

新增两项回归检查：完整61阶段的双臂软弯、前伸、平面与对称性；完整人体在躯干前倾时前臂形状和法线不扭转。修复前第一项能复现失败，修复后全部通过。

附带“手臂修正对比.png”和“深蹲修正预览.gif”，均为应用相同Kotlin模型/投影代码的离线渲染；GIF为侧面、斜侧、正面三个视角。不是手机截图/录屏，真机显示和帧率仍待验收。

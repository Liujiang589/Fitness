# 独练 V1.20 · 计划创建与编辑

2026-10-26。修正创建入口与后台忙碌状态共用禁用条件的问题，重排创建和编辑计划。

## 入口

首页“今天 / 计划库”右侧有固定“＋ 创建计划”。首次使用的“创建我的计划”、计划库“＋ 新建”和快捷菜单进入相同编辑器。没有实际训练可启动的导航按钮，不再因为无关后台操作忙碌而禁用；真正开始训练仍保留忙碌时禁止重复操作的约束。

## 页面

- 全屏浅灰背景、白色分区、统一字体层级和固定底部保存按钮，替代拥挤的小弹窗。
- 先填写计划名称、选择动作，再查看默认组数/次数和可选训练日；休息、训练方案、超级组收进进阶设置，保留专业选项。
- 单独的动作选择页支持名称、肌群、器械搜索，以及肌群筛选；完整动作库按需加载，移除原来只显示前12项的限制。
- 已选动作按训练顺序展示，支持上移、下移和移除；返回编辑器后选择保留。
- 新建默认3组×10次、休息沿用全局设置，训练时可单独调整；编辑原计划保留ID、方案、编排、排期及数值。

## 保存与退出

保存按钮在实际事务完成之前显示“正在保存”，阻止重复提交；成功后才关闭并显示已保存提示。输入错误在按钮上方说明；数据库保存失败仍保留填写内容并允许重试。修改后取消会询问是否放弃；旋转屏幕时保存编辑器入口、原计划和草稿字段。

# 独练 V1.23 · 走跑启动稳定性修复

2026-10-26。Android 8.0以上，原包名、原签名，可直接覆盖安装，不先卸载旧版。

## 安装与检查

1. 打开独立文件“独练-V1.23.apk”覆盖升级；ZIP用于归档或转交，里面也有同一个APK。
2. 进入“步行与跑步”，先选择步行，准备后点击开始；再检查跑步流程。
3. 网络辅助定位仍由用户选择。辅助定位中断时会显示提示，系统定位、计时与传感器计步继续按已有权限工作。
4. 如果仍然闪退，重新打开独练，进入“我的 → 异常诊断 → 复制信息”，将内容提供给开发者。无需连接电脑。

## 本轮处理

替换存在缺失类引用风险的高德组合SDK，删除此前隐藏这项缺失依赖的Release构建规则。新增依赖完整性测试，以便以后升级SDK时及时发现同类问题。

将高德网络辅助定位客户端及其APS服务移到独立进程。主进程负责计时、系统GPS、传感器和记录；辅助进程停止或失去连接时，主进程提示并继续使用系统定位。街道地图渲染仍在界面进程，不在本轮辅助定位隔离范围内。

加入本地异常诊断：记录版本、进程、线程及Java异常调用链；Android 11及以上还尝试读取系统保存的Java/原生异常退出摘要。内容不自动上传，只有点击复制才写入剪贴板。常见Key、令牌、经纬度赋值会被隐藏；发出前可以检查文本。诊断信息不保证包含所有系统或原生崩溃的堆栈。

本轮未调整距离/速度质量门槛、日常步数口径、计划与营养数据、数据库schema1、备份v4及原有WGS84轨迹。网络位置仍只用于显示，不计作运动距离。

## 验证边界

已完成构建、单元测试及APK静态校验。暂时没有连接用户手机，没有取得这次实际崩溃堆栈，也没有在该手机复现和确认修复；缺失依赖是已发现并移除的具体风险，不能据此断言它就是用户每次闪退的唯一原因。安装后仍需要按上述流程检查。

# 独练 0.12.0：轻松阅读，保留专业

本轮针对“数字过多、阅读有负担”的用户反馈，调整原生 Compose 页面。展示顺序变成：现在做什么、当前状态、按需查看专业指标。

## 页面调整

| 页面 | 默认看到 | 按需展开或切换查看 |
|---|---|---|
| 训练首页 | 明亮训练主视觉、今日计划与开始按钮、本周打卡 | 本周次数、容量、连续天数；计划动作、组次、训练方案与休息设置 |
| 正在训练 | 当前训练状态、休息剩余或总用时、下一组、重量和次数输入 | 本次完成组数、容量与总用时 |
| 饮食 | 高清餐食配图、食物与克数、供能构成色条 | 蛋白质、碳水、脂肪、饮水及单份营养明细 |
| 历史 | 训练日历与记录列表 | 切换“身体与饮食”或“专业分析”；展开单次记录的全部组和递进建议 |
| 工具 | 计时器与计算器的主要操作 | 1RM强度配重表、动作表现 |
| 我的 | 个人入口、身体记录、设置与备份、作者联系 | 累计训练、累计容量、连续天数 |

训练进行时首页只呈现当前训练，不再继续堆放其他计划和模板。记组控件持续保留，避免折叠动作导致尚未保存的输入丢失。计时器和HIIT也保留原有组合生命周期。

## 专业能力

重量、次数、组类型、RPE、独立休息、超级组、上次对照、自动保存、容量计算、1RM、训练负荷、肌群分布、平台期、身体曲线、营养来源及备份继续可用。本轮不修改数据库、备份结构、训练公式或食物换算算法。

供能色条只表示已记录食物中蛋白质、碳水和脂肪的能量比例（4/4/9），不是目标达成率。没有个人目标时不显示虚构的完成百分比。主视觉不代表实际训练动作或标准餐食份量。

## 图片与排版

使用 imagegen 技能的内置 image_gen 工具生成原创氛围照片，完整提示词保存在 [UI012_IMAGE_PROMPTS.json](UI012_IMAGE_PROMPTS.json)。原生输出1536×1024，保持原尺寸转为WebP quality92，没有用插值放大冒充更高分辨率。两张图片都随APK离线打包，无需联网加载。

- `android/app/src/main/res/drawable-nodpi/training_daylight.webp`：日光训练室，放松状态的成年训练者；用于首页和动作库的氛围横幅。
- `android/app/src/main/res/drawable-nodpi/nutrition_daylight.webp`：自然光下的日常餐食；用于饮食和身体趋势入口。

文字保留原生可缩放排版，照片不烘焙文字。横幅采用最小高度而非固定高度，字体放大时允许卡片增高；历史分类横向可滚动。展开控件最小高度48dp，提供展开状态语义并保存展开状态。照片作为装饰，不重复播报；肌群定位沿用可缩放的原生矢量示意。没有加入未经动作审校的视频。

# 独练 V1.11：今天的训练与动作指导

第二批优化，2026-10-23。Android开发调试版，versionName1.11 / versionCode25。

## 首页：先看今天，再管理计划

“训练”首页分为“今天”和“计划库”。

- 今天：首先展示符合已有计划和历史记录的主卡片，再放步行跑步、动作学习入口、本周足迹及饮食/身体记录入口。不再默认铺开所有计划、模板、营养数字和诊断指标。
- 计划库：查看、新建、编辑、复制和删除原有计划；展开计划内容、逐个查看动作要领；可选模板和周排期也在这里。
- 训练进行中：优先显示正在练的内容和记录操作；下一组与各动作都有指导入口，关闭指导回到原训练。

今日卡片区分：首次使用创建计划、当天有未完成排期、无固定日期的自由选择、无当日排期以及今日已训练。当天完成情况按planId及训练开始日期判断，不用同名计划猜测；多个排期先显示尚未完成的一份。只有用户点击才开始训练，不自动建计划或指定训练负荷。

日期在应用前台定期更新，返回应用时刷新；跨日后按新日期展示排期。周数据仍可展开，饮食明细仍在饮食手记，专业分析仍可在历史中查看。

## 动作：先看重点，再按需展开

40个基础动作继续使用原有原创矢量动态示范，支持播放/暂停、慢放、进度拖动、关键阶段、侧面/斜侧和放大。图形按屏幕像素渲染；首页复用现有1536×1024高清训练图片，不依赖新的视频下载或用户上传图片。

每个动作增加独立的“先记住这一点”短提示。指导按三个主题组织：

1. 动作要领：呼吸与控制直接可见，展开“完整分解说明”查看准备、发力和还原；高亮随播放器阶段变化。
2. 常见错误：保留动作专属错误提示，便于练习时逐项核对。
3. 替代动作：展示已整理的器械/动作变化、选择理由及差异，可直接打开替代示范，再回到原动作。

替代关系由项目逐项整理，不能理解为所有动作完全等效、适用于伤病或默认更简单。比如引体向上对自重能力要求更高；划船变式的躯干支撑、站坐姿和器械不同；腿屈伸换腿举会从单关节变成多关节。腿弯举、侧平举等未整理合适替代的项目会明确提示，避免仅按相同肌群强行匹配。

查看替代示范不写入数据库。要实际更换计划动作，在计划编辑中自主选择并重新设置负重。查看替代时不能编辑/收藏一个临时生成的动作；原动作的个人备注、照片、默认重量仍保留。训练进行中指导采用只读模式，不显示动作编辑或删除入口。

## 专业内容与兼容

保留全部动作、组数、次数、重量、平均/统计指标及详细记录；本轮主要改变信息层次。未知自定义动作仍不匹配一个相似但不正确的示范，可查看个人要点。

未修改数据库schema、备份v4结构、应用包名、签名或高德配置。V1.10户外记录功能保留。完整备份可能包含位置，继续由用户通过系统文件选择器导出。

中文要领与替代说明为项目原创整理，参考[ACE动作库](https://www.acefitness.org/resources/everyone/exercise-library/)及[ACE背部训练文章](https://www.acefitness.org/resources/pros/expert-articles/8944/a-back-to-school-program-an-evidence-based-approach-to-training-the-back/)所列动作模式和练法；并非ACE授权/出品的动画或由其逐项审校的处方。没有打包第三方私有动作媒体。

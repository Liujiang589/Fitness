# 独练 V1.19 · 走跑体验

2026-10-26。围绕“准备—出发—运动—暂停—回顾”整理步行与跑步。

## 使用

1. 进入步行与跑步，选择步行或跑步，点击准备。首次会说明GPS用途并请求必要权限。
2. 准备时使用临时GPS定位，不计时、不生成或保存运动记录。得到新鲜、精度达标的定位后，点击开始，倒数3秒出发。可以取消倒数或取消准备；离开准备页会取消准备，90秒未开始也会停止准备定位。
3. 运动中同屏查看距离、时间、当前配速（步行显示速度）与街道地图。步数为本次已采集值，详细口径、权限与亮屏开关收进运动设置。
4. 位置和精度圈只向收到的测量结果过渡，不预测未来位置。手动拖地图后停止跟随，点回到当前位置可恢复；开始或继续运动会开启跟随。查看全程不会连接暂停和失联的断点。
5. 点结束或放弃，先暂停再确认。返回运动页保持暂停，继续后才恢复记录。保存的运动进入足迹；放弃只移除本次运动，当天已采集步数保留。

## 流畅度实现

- 屏幕外壳、仪表、计时与地图分别订阅所需状态；计时变化不使地图和历史列表重新处理整条路线。
- 路线分为最多64点的小块，邻块共享端点；追加定位只更新活动尾块，历史块保留。14000点路线追加一条定位的检查中，仅一个不超过64点的块需要上传。
- GPS请求间隔改为1秒；距离仍由原有质量门槛与可靠采样决定，不能把每秒请求等同于每秒一定有有效位置。
- 地图标记与镜头使用750毫秒显示过渡；不移动的位置不重复启动动画。距离只向已测量的目标值做650毫秒视觉过渡，持久化距离和GPX不使用动画坐标。
- 跑步当前配速以5秒/公里的显示粒度降低闪动。缺少单条速度候选时最多短暂保留最近读数6秒；定位过期或信号不足时隐藏速度，不把失联当静止。

# 独练 V1.22 · 网络辅助定位与快速开始

2026-10-26。针对室内长时间等卫星、定位后才能开始的问题，加入网络辅助位置和弱信号下的开始流程。

## 怎么用

1. 覆盖安装V1.22，进入步行与跑步，选择步行或跑步，点击准备。
2. 首次显示定位方式说明。可以勾选“使用高德网络辅助定位”，阅读高德隐私政策，允许系统精确定位并保持联网。不勾选时仅使用系统定位。
3. 也可以先进入“定位设置”保存选择；保存设置本身不会启动定位或创建运动。下次运动前可以重新调整。
4. 准备页区分最近缓存位置、网络当前位置和路线定位就绪，显示位置误差估计。准备阶段不计时、不保存运动。
5. 路线信号较弱时仍可点击“先开始计时与计步”，倒数3秒开始。手机不支持计步或未授权身体活动时，按钮改为“先开始计时”。
6. 运动中优先显示可靠卫星位置；暂时没有可靠路线时，地图可显示网络估计位置及误差圈。路线距离和配速只来自合格卫星采样；网络位置不累加里程，不生成虚假路线。室内可能只有时长和步数。
7. 暂停、取消准备或结束时停止辅助定位；日常计步不会启动它。

## 接入方式和边界

系统GPS继续以1秒请求可靠路线位置；系统网络位置与用户同意后的高德Wi-Fi/基站辅助并行，用于尽早显示当前位置。高德客户端使用网络定位模式，避免再启动一套卫星采样。

缓存位置最多显示30秒，并标注最近位置；过期或无效位置丢弃。高德返回的GCJ02坐标直接用于街道地图，系统WGS84位置按原流程转换；历史轨迹与GPX保持WGS84。

这会改善可用位置来源和开始流程，但不保证室内房间/楼层级精度、秒级首次定位或准确室内路线。实际精度取决于Wi-Fi/基站覆盖、联网、授权和设备；本版尚未在用户手机实测。高德失败时提示并继续使用系统定位。

## 联网与数据

选择高德辅助后，高德SDK会处理定位所需的位置信息、附近Wi-Fi/基站、设备及网络信息。SDK在授权且准备/运动时才启动；停止时销毁客户端，关闭其停止后的基站更新和服务自启动选项。街道地图仍单独授权。轨迹和训练/营养记录保存到本机，定位服务请求不等同于上传整份训练记录。

参考[高德定位模式说明](https://lbs.amap.com/api/android-location-sdk/guide/android-location/getlocation)、[高德参数与坐标选项](https://a.amap.com/lbs/static/unzip/Android_Location_Doc/com/amap/api/location/AMapLocationClientOption.html)、[高德隐私政策](https://lbs.amap.com/pages/privacy/)。

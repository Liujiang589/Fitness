# 独练 V1.3：动作动态示范

日期：2026-10-23。本轮重做“动作”页，从肌群分类小图改成可观看、暂停和分解的原创动态小人。

## 用户可以直接使用的内容

- 现有40个基础动作全部有对应示范，7套计划模板中的动作也全部覆盖。
- 卡片显示动态预览、动作名称、肌群、器械和要领入口。保留搜索、肌群/器械组合筛选、收藏、自定义动作。
- 点击动作可观看更大的示范，暂停、播放、0.5倍慢放、拖动进度、选择关键阶段，并切换侧面/斜侧观察。还可单独放大播放器。
- 每个动作都有3段技术说明、2项常见错误、呼吸提示与主要肌群。
- 原生矢量逐帧绘制，可离线播放，按屏幕像素实时渲染；没有用模糊小GIF放大，也不依赖用户上传图片。

动作页同时只播放可视区域中占比最大的一个卡片，其他卡片停在静态姿势。离开页面或应用进入后台会停止帧循环；关闭系统动画时默认静止，用户仍可手动控制详情播放器。

旧照片和个人备注仍保留在本地数据中；已存照片仅放在“个人训练设置”中查看。删除了添加/更换照片入口和“请自行上传图片”的默认引导。

## 实现与数据兼容

- `domain/ExerciseGuides.kt`：40条独立动作条目、分解说明、错误提示及精确名称/器械匹配。
- `domain/MotionEngine.kt`：原创三维关节坐标、双骨骼逆运动学、动作专用轨迹与器械场景。
- `ExerciseMotion.kt`：原生Canvas投影绘制、分层着色、暂停/慢放/拖动/视角/放大与生命周期控制。
- 动作名称和器械都相符才自动匹配；未知自定义动作或被改成其他用途的旧ID不会套用相近但错误的示范。
- 包名、签名、数据库及备份v3不变，不重建动作库，不覆盖用户记录或备注。

手臂小幅固定屈肘的动作（飞鸟、平举、直臂下压）使用圆弧与固定肘角轨迹；弯举和臂屈伸保持上臂稳定。俯卧撑使用整体身体连线，臀桥检查顶端躯干和大腿对齐，引体向上固定握点。器械、长凳、绳索、横杆与地面支撑按动作分别配置。

## 来源与边界

全部人物图形、动作路径和中文要领由本项目编写，没有提取训记的私有素材，也没有导入第三方动作媒体。技术资料参考入口为[ACE公开动作库](https://www.acefitness.org/resources/everyone/exercise-library/)；研发期间也核查了[wger公开API文档](https://github.com/wger-project/docs/blob/master/docs/api/api.rst)及公开视频条目，但本次未将其视频或图片打包。

原创动画展示常见动作路径，不是ACE或wger出品、授权或审校的动画。姿态几何检查、代码测试及预览审查不等于持证教练逐项审校，不能据此声称适用于每个人的活动范围、伤病或训练负荷。

## 可复核预览

运行JVM测试时，实际Kotlin运动引擎会导出40个动作的3个关键姿势和每个动作48个循环帧，存入`android/app/build/reports/motion-keyframes.json`。运行`python tools/render_motion_previews.py`可重新生成[姿态检查图](motion/poses-1.png)和[动作路径预览GIF](motion/motion-preview.gif)。

这些图由实际关节数据绘制，用于核对姿态、器械和运动路径，绘制效果与原生Canvas略有差异，**不是手机界面截图**。最终构建、检查及交付结果见[V1_3_VERIFICATION.md](V1_3_VERIFICATION.md)。

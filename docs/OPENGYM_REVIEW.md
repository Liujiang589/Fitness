# openGym 与独练：对照记录

查阅日期：2026-11-02。依据公开文档和项目配置，未安装或实测 openGym；功能覆盖不代表稳定性评测结果。

共同定位：训练计划、逐组记录、动作库、训练回顾，以及本机使用与数据导出。

openGym 文档展示了更广的动作库、个人资料同步和苹果设备支持。其移动应用以 React / Capacitor 为基础；独练安卓端使用 Kotlin / Compose，不能直接将它的网页组件塞入现有原生页面。

- [项目说明](https://github.com/DuarteSantos8/openGym)
- [前端依赖配置](https://github.com/DuarteSantos8/openGym/blob/main/frontend/package.json)

值得借鉴的产品方向：训练界面减少按钮干扰，突出当前组和上次表现；用易读的肌群概览解释训练分布；按训练现场需要提供替代动作和清楚的进步依据。

其通行密钥/可选密码登录与自部署同步，不能直接等同于独练所需的微信、QQ、短信认证。后者仍需认证服务、账号数据归属及对应平台接入。

代码许可证为 AGPL-3.0；动作媒体另有许可。项目 NOTICE 说明 Gym visual 动作图片/动画不能直接抽取到独立应用，需要取得自己的授权；人体部位图的几何数据另标明来自 MIT 许可的 MuscleMap。后续若采用任何代码或资源，需要逐项核对来源和许可，不能将整个仓库视作可任意搬用的素材库。

# 独练 V1.27 · 稳定性优化

本轮针对安卓训练输入、走跑计步和保存交互。versionName 1.27 / versionCode 41。

## 本次变化

- 重量、次数自动保存时不再触发整页忙碌状态，减少输入过程中按钮反复禁用和进度提示闪动。明确的暂停、完成等操作仍会锁定输入，等待保存结果。
- 只有数据库写入成功才清除待保存输入。失败时保留当前进程内的草稿，显示“重试保存输入”；取消的写入和后来输入的新值也不会被旧写入误清除。
- 走跑结束或放弃记录，确认框等待服务处理结果；处理时阻止重复点击，失败留在确认框提示原因并允许重试。
- 当天计步和运动计步统一先过滤重复、乱序、过期及不属于本次传感器订阅的旧事件。重新开启计步时重新建立基线，避免将停用期间累积的读数突然补入。
- 定位回调先复制位置，再等待处理，避免延迟处理时读取可变的回调对象。
- 正在训练时，不再随每次输入保存重新计算首页的历史观察和推荐。

## 安装

直接打开同目录的 `独练-V1.27.apk`，按系统提示覆盖安装。支持 Android 8.0 及以上，沿用原包名和签名，无需先卸载。升级前建议在“我的 → 导出全部数据”备份。

ZIP 是归档交付包；直接安装请用独立 APK。微信预览 ZIP 不等于系统安装界面。

## 验证范围与后续验收

本轮不操作用户手机。构建、自动测试、签名和压缩包检查结果见同目录验证记录；新增界面测试仅编译，未在设备执行。不能据此声称真实定位更精确、首定位更快或滑动帧率已改善。

建议后续实机核对：创建计划并输入多组记录后暂停/继续；误开走跑后放弃；正常走跑后保存；关闭再开启计步；开阔室外与遮挡环境下的定位提示、距离变化；大字号手机上的布局。

输入保存失败时草稿只保留在当前进程，强制停止或杀进程后不能保证恢复，请保持应用运行并重试。计步仍依赖系统传感器、权限和服务存活，本版没有补齐应用停用时的全天步数。

账号功能仍是准备页面，未接通真实注册、短信、微信或 QQ 登录。苹果网页版保持暂停；本次未更新下载网站、二维码或在线更新清单。

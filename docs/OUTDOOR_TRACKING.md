# 独练 V1.10：高德街道地图、步行跑步与每日计步

2026-10-23。开发调试版。训练首页“步行与跑步”或右上角快捷菜单进入；保留力量训练、40个动作动态示范、饮食换算与作者联系。

## 开始使用

1. 安装后进入“步行与跑步”，点“开启街道地图”，阅读说明与高德隐私政策，自主同意后加载地图。首次加载需要联网；可以单独关闭地图，不影响本机运动记录。
2. 点“开始步行”或“开始跑步”，授予精确定位并打开手机定位，到室外等待 GPS。没有有效定位时不伪造当前位置。默认地图视野不能代表手机实际位置。
3. 运动页主卡片显示距离、运动时长及当前配速（跑步）或速度（步行）；定位状态独立展示，地图支持跟随、全程、全屏。底部固定暂停/继续与结束保存按钮；“配速、步数与定位详情”内保留平均配速、当前速度、步数和精度。默认不保持亮屏，可按需开启。
4. 暂停时停止 GPS，继续后另起一段；结束需确认，成功后显示本次总结，保存到“运动足迹”。历史可回看地图、平均速度、配速、GPX；精确坐标折叠在详情中。未启用或不支持街道地图时，已有轨迹可显示本机路线示意，明确标记非街道地图。
5. 日常计步单独开启，使用身体活动权限和手机计步传感器，不开启 GPS。可以查看近七天；未采集的日期明确显示“未采集”。缺少计步硬件或拒绝身体活动权限仍可记录 GPS 运动。
6. “我的 → 导出全部数据”为 duolian-native v4，包含户外轨迹和每日步数，兼容导入v1–v3。导入前需结束运动并关闭日常计步；恢复未结束户外记录时保持暂停，不自动启动GPS。

## 记录口径和恢复

- 今日步数从开启采集后累计，不读取微信或其他健康应用的全天历史。首个传感器读数只作基线；跨日、重启或计数器回退重新建基线，不猜测分配无法可靠归属的步数。夜间边界或系统清理可能少计。
- GPS 原始坐标为 WGS84，距离按有效定位点估算；地图显示前使用高德转换到其地图坐标，原始数据库和GPX坐标不改写。相邻点超过30秒另起段，暂停/失联不补直线距离。过滤精度差于35米、陈旧、微小抖动和明显不合理的跳点，仍可能有GPS漂移或少计。
- 当前速度优先使用GPS地面速度，精度不足时根据短间隔有效位移估算；拒绝无效值、跳点、跨段及过长间隔。跳点也不能给实时速度供值。暂停或十秒没有有效速度时显示“—”。当前配速由速度估算；平均速度/配速使用非暂停时长及已记录距离。等待GPS的非暂停时间也计入时长。
- 请求GPS间隔为两秒，实际返回频率由设备和系统决定。每场最多14,400个接受点；最密集时约八小时，达到上限提示结束并新开运动。
- 用户主动开启后通过前台服务请求定位/计步，锁屏及切到其他应用时继续请求。没有始终允许定位权限，也不会开机自动启动GPS。重启、强制停止或厂商省电清理会中断；正常运行约每五秒保存检查点，开始/暂停/继续/结束立即保存；强停仍可能丢失最近未保存的几秒。路线编码解码在后台线程处理。重开后可继续未结束运动，未运行期间的时间不计入运动时长。
- 定位关闭后自动暂停，重新开启后需要用户点击继续。通知可暂停或回到页面，结束需在页面确认。开关日常计步不会重启当前 GPS 或重置运动步数基线。活动 GPS 会话持有有时限的可续期 CPU 唤醒锁，暂停、结束与销毁释放，日常计步单独运行不持锁；不是强制绕过系统省电，真实耗电仍需验收。
- 地图当前原生引擎支持ARMv7/ARM64；不支持的设备会提示，保留本机计步及GPS记录。弱网/断网可能无法加载新地图，但已采集记录仍可保存。

## 数据、权限与隐私

户外数据保存在现有Room数据库，schema仍为1，不清空用户旧数据。GPX、v4完整备份、自动备份以及导入前恢复副本可能包含精确位置，用户通过系统文件选择器决定保存与分享；删除一条运动同时删除该条轨迹，已导出的副本和先前备份需用户自行管理。完整备份上限32MiB，可逐条导出GPX后清理历史。

高德街道地图是在线服务，由北京高德图强科技有限公司提供。用户同意开启前不初始化地图SDK；开启后SDK按其政策可能处理位置、IP地址、设备和应用信息，并联网请求地图。不能把本地记录简单理解为第三方完全不处理任何位置相关信息。本应用未启用轨迹云服务，也未启用高德定位、搜索或导航；GPS采集仍使用Android系统。离开/关闭地图时销毁视图，应用前后台对应暂停/恢复。

使用精确/粗略定位、身体活动、通知及location/health前台服务权限；新增网络状态权限用于地图联网。新增普通 WAKE_LOCK 权限用于 GPS 锁屏记录，不申请始终允许定位、电话、通讯录或 Wi-Fi 扫描权限。

高德隐私政策：https://lbs.amap.com/pages/privacy/

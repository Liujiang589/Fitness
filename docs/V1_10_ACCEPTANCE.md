# 独练 V1.10：手机体验清单

建议先导出全部数据，再覆盖安装独练-V1.10.apk，不卸载旧版。保留原包名和签名；仍为开发调试包。

## 一次约 15 分钟的体验

1. 打开“步行与跑步”，选择步行或跑步，到室外开阔处开始。寻找 GPS 时应有明确提示；距离在收到可靠位置前保持零，运动时长从开始后计入。选择是否开启高德地图，不同意地图仍能记录并查看本机路线示意。
2. 正常走或跑 3 分钟。主卡片显示距离、时长和当前配速（跑步）或速度（步行）。步数、平均配速、定位精度在“配速、步数与定位详情”内；没有可靠实时速度时显示“—”。
3. 暂停 1 分钟，移动几步，再继续。暂停期间时长、路线和本次步数不增加；继续后的首段不连接暂停期间的缺失距离。传感器在恢复后的首次读数只作基线，可能少计刚开始的一小段步数。
4. 锁屏 5 分钟继续运动，再解锁；也可切到其他应用。应持续显示前台记录通知，解锁后时长衔接、路线仍在记录。通知上的“暂停运动”应暂停，“查看 / 结束”应回到页面，不能一次误触就结束。厂商省电策略可能限制后台，需要实机判断。
5. 结束并确认保存，应看到“这一程，已为你保存”和路线示意。在运动足迹中查看地图、统计、GPX 导出；导出的路线不应跨暂停或缺失位置连线。
6. 回到力量训练、饮食、我的，检查原计划和记录仍在。“我的”显示 V1.10，安卓桌面和安装包名称均为独练。

## 补充边界（可分次测试）

| 场景 | 预期 |
| --- | --- |
| 关闭网络，保留手机定位 | GPS 可独立记录；提示地图网络未连接，不承诺新街道底图可用。恢复网络后可重试地图。 |
| 室内/遮挡导致弱信号 | 定位状态清楚；无可靠速度时不沿用旧速度，缺失路段不补画直线；非暂停时长继续累计。 |
| 关闭系统定位或撤回精确定位权限 | 运动暂停；恢复开关/授权后由用户点击继续，不悄悄重启定位。系统撤权可能直接结束进程，按检查点恢复处理。 |
| 强制停止应用，再重新进入 | 检查点保留；明确发现未结束运动，可继续或结束保存。停掉进程期间不补计时、不补路线，最后未保存的几秒可能丢失。 |
| 暂停后离开页面，再返回 | 保持暂停；亮屏选项不会让其他页面持续亮屏。 |
| 无计步硬件/拒绝身体活动权限 | GPS 路线和时长仍可记录，步数不伪造。日常计步独立开启，不启动 GPS。 |
| 连点暂停、继续、保存 | 操作期间按钮禁用，已有未结束运动不能被新运动替换。 |
| 系统时间向前/向后校准 | 运动时长按单调时钟累计；GPS 样本用同一会话的时间锚点，避免距离/速度由墙上时钟跳变产生异常。 |

距离与耗电需要实测：选开阔处约 1 公里固定路线重复两次，记录机型、系统版本、起止电量、实际时长、应用距离、是否亮屏及异常截图。模拟定位测试不能证明真实 GPS 精度或耗电水平。
